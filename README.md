# オープニング連動サイト

| ファイル | 使う人 | 内容 |
|---|---|---|
| `screen.html` | プロジェクター | QR・接続人数カウンター → 3・2・1 → 色が変わりタイトル表示 |
| `index.html` | 来場者のスマホ | QRで開くページ。合図で画面が一斉に同じ色に光る |
| `control.html` | 発表者のスマホ | 操作パネル。**発表者のGoogleアカウントでしか操作できない** |

操作の制限はページ側ではなくデータベースのルールでかけています。来場者がURLを推測して `control.html` を開いても、書き込みは拒否されます。

## セットアップ（30分ほど）

1. **Firebaseプロジェクトを作る**
   https://console.firebase.google.com で新規プロジェクトを作成（Googleアナリティクスはオフで可）。

2. **Realtime Database を作る**
   「構築」→「Realtime Database」→「データベースを作成」。リージョンは `asia-southeast1`（シンガポール）、ロックモードで開始。
   「ルール」タブに `database.rules.json` の中身を貼り、`YOUR_EMAIL@gmail.com` を**発表者のGmailアドレス**に書き換えて公開。

3. **ログイン方法を有効にする**
   「構築」→「Authentication」→「Sign-in method」で **匿名** と **Google** を有効化。

4. **設定値を貼る**
   「プロジェクトの設定」→「マイアプリ」でウェブアプリ（</>）を追加。表示された `firebaseConfig` の値を `config.js` に貼る（`databaseURL` も必要）。

5. **公開する**（どちらか）
   - かんたん：https://app.netlify.com/drop にこのフォルダをドラッグ＆ドロップ
   - Firebase Hosting：`npm i -g firebase-tools` → `firebase login` → `firebase init hosting` → `firebase deploy`

6. **公開先のドメインを許可する**
   Authentication →「設定」→「承認済みドメイン」に公開先（例：`xxxx.netlify.app`）を追加。これをしないとGoogleログインが失敗します。

## 本番の使い方

1. PCで `screen.html` を開き、プロジェクターに全画面表示（F11）
2. 自分のスマホで `control.html` を開き、Googleでログイン
3. タイトルと色を入れて「タイトルと色を反映」
4. 来場者がQRを読み取る → 人数が増えていく
5. 合図とともに「3・2・1 スタート」→ 全員の画面が同時にカウントダウン → 一斉に点灯
6. やり直すときは「待機画面に戻す」

## 動画と投票

- 動画は `videos/video1.mp4`（コンテスト作品）と `videos/video2.mp4`（呼び込み動画）に置きます。今は5秒の仮動画が入っています
- 質問・選択肢・比較する数字は `videos.js` で変更できます（1本目は多摩祭の子どもたちの72.8％と比較）
- 本番前に発表画面の「🔊 クリックして音声を有効にする」を一度押してください。押さないとブラウザが音声付き再生を止めます
- 操作パネルの各動画で「▶ 上映 → 投票開始 → 締め切り」の順に押します。締め切り後はスマホから投票できません
- リハーサル後は「投票をすべてリセット」で票を消してください

## 発表画面からの操作

- 発表画面でマウスを動かすと、右下に「◀ 戻る」「次へ ▶」が出ます（2.5秒で自動的に隠れます）
- キーボードやプレゼン用リモコンでも操作できます：→・Space・PageDown・Enter で次へ、←・PageUp で戻る
- 待機画面で「次へ」を押すと 3・2・1 が始まります
- 初めて操作するときに発表者のGoogleアカウントでのログインを求められます。操作できるのは発表者だけです

## 注意点

- **同時接続100人の上限**：無料プラン（Spark）は同時接続が100までです。来場者が100人を超えそうなら、従量課金プラン（Blaze）に切り替えてください。この規模なら料金はほぼ0円ですが、クレジットカードの登録が必要です。
- **画面スリープ**：参加者に「準備OK」を押してもらうと、対応端末では画面が暗くなりません。口頭でも「画面を開いたままにしてください」と伝えてください。
- **会場の電波**：事前に会場で、自分＋数人のスマホでリハーサルしてください。つながらない人がいても、発表画面の演出だけで成立します。
- **手元での確認**：ファイルを直接ダブルクリックしても動きません。公開後のURLで確認するか、このフォルダで `npx serve` を実行して試してください。
